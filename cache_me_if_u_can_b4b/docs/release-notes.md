# Mashq v1.0-submission — release notes (draft)

Mashq (مشق, "practice") is an Android app that helps parents and grandparents practise online forms in a safe, fictional setting. It teaches the person to do the task themselves and never does it for them.

## Install (judges)
1. Download `<APK file name>` from this release on your phone.
2. Open it. If Android warns about an unknown app, tap **Install anyway**, and allow installing from this source if asked.
3. Tested on Android `<versions: verify>`.

## Use
- Open **Lessons** and start Lesson 1. A PRACTICE banner shows that nothing is real.
- Use **Guide me on websites** on Home to open the Guide browser. It explains each box on a web form. It never fills anything in and never reads what you type.

## Known limitations
- The practice forms and the Practice Person are simulated.
- Only Lesson 1 is bundled.
- Video results come from a curated list and cache; live search needs the optional server.
- The Guide finds standard form fields only.
- Urdu audio is generated speech; Urdu text is pending native review `<verify>`.
- Sideloaded prototype, not on the Play Store.
